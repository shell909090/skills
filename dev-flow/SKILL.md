# 开发流程

本技能提供需要阶段确认和文档追踪的开发流程。迁移、审查或编辑本技能本身不代表启动该流程。

显式调用后，阅读 [完整流程与文档格式](references/workflow.md)，确认当前阶段后执行。保留需求、任务、设计、审查和归档之间的对应关系；设计确认、质量控制、问题回流和阶段交付按该参考执行。

依赖项目使用的 Git、构建、测试和质量检查工具，没有统一的安装命令或服务凭证。工作文档使用目标项目约定的目录，不写入技能安装目录。发布、部署和推送仍以用户授权范围为准；本技能不自动授权这些操作。

仓库已定义文档位置、语言和 Git 跟踪策略时，沿用项目约定；参考中的文件名是默认约定。覆盖率等指标只报告实际测得的结果，无法测量时说明。

支持调用策略的客户端读取 `agents/openai.yaml`；其他客户端仍应遵守仅显式调用的文字约定。
