# yt-dlp 媒体下载

使用现有环境处理用户有权访问和保存的媒体。视频、音频、字幕及网页直链的具体命令见 [下载示例](references/downloads.md)。安装、升级和 YouTube runtime 故障见 [环境与排错](references/setup.md)。

## 工作流程

1. 检查 `command -v yt-dlp`、`yt-dlp --version`、`command -v ffmpeg`、`command -v ffprobe`。FFmpeg 用于音视频合并和转换，需要可执行文件，不是同名 Python 包。
2. 确定用户需要的媒体、格式、字幕语言和输出目录。使用用户或项目约定的目录；没有约定时使用当前目录的 `downloads/`。临时诊断数据放系统临时目录下的独立任务目录，结束后清理，不写进技能仓库。
3. 默认 `--no-playlist`，仅在用户要求时下载整个播放列表。需要确定格式时先用 `-F`，字幕语言用 `--list-subs`；不要默认重新编码或强制 MP4。
4. 下载后核对实际文件及处理结果，报告路径、格式、大小；失败时说明关键错误，不声称已完成。

## 操作边界

- URL、路径和格式作为独立 shell 参数并正确引用；不使用 `eval` 或拼接未经引用的命令。
- 下载授权不自动包括读取浏览器 cookies、使用登录态或付费服务；需要时取得相应授权。已有明确授权不重复询问。此技能不要求 GPG 凭证。
- 安装、升级遵循用户授权和当前环境管理方式；不要默认切换到 nightly，或修改全局 pip 配置。
- 不绕过 DRM 或访问控制。不把 cookies、带签名媒体 URL 或原始详细日志中的秘密公开输出。共享诊断前先脱敏。
- 报告是否使用登录态、是否升级以及升级前后版本，不输出秘密值。
